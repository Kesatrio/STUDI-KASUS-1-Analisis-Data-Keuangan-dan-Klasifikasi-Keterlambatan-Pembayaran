# Studi Kasus 1: Analisis Keuangan & Klasifikasi Keterlambatan Pembayaran
Deskripsi
Studi kasus ini mensimulasikan kebutuhan analisis data transaksi di perusahaan retail/distributor (seperti studi kasus PT Maju Bersama). Tujuannya adalah untuk membersihkan data dan melatih model Machine Learning dalam memprediksi apakah suatu transaksi atau invoice berpotensi mengalami keterlambatan pembayaran (late payment).
